## Release Tag: v3.4.0

-Improved internal solar zenith angle (SZA) calculations for greater consistency across E-CHAIM language versions (IDL, C, MATLAB).
-Previous SZA threshold calculations caused discrepancies near internal boundaries; these have been reduced from ~0.006% to ~0.000002% of outputs within our test grid.

## Release Tag: v3.3.0

-The methods in which E-CHAIM interfaces with AACGM and its coefficients has been simplified
-Improved the solar zenith angle calculation
-The E-CHAIM primer has been updated

## Release Tag: 1.2.0

* An ‘expected output’ text file has been added to the examples folder. This file contains the expected output if the user runs the examples.c code. This is intended for the user to ensure that all parts of the model have been installed and compiled properly.
* Improved the user front end ‘ECHAIM.c’ so that longer input lines can be used in the input file. Error checking has been added to alert the user if the lines lengths are too large.
* Fixed a bug where the storm perturbation would be incorrect if a time resolution of less than 1 hour was used. This would occur for times before 1 hour UTC and later than 23 hours UTC.
* The efficiency of the storm perturbation calculation routines have been significantly improved at the loss of the storm option array input for the density and satellite path functions. This means the user can longer choose some inputs to be calculated with the storm perturbation and some without for a single run of the above functions. The storm option is a not an integer, switching the storm perturbation function on or off for the entire input data set.
* The AACGM components of the model have been updated to version 2.5. This includes the AACGM functions and the coefficients.


## Release Tag: 1.1.1

Storm NmF2: Increased stability during large (Kp > 8+) geomagnetic storms. Improved performance in data-sparse regions.


## Release Tag: 1.0.1

Bug fix: Negative NmF2/hmF2 values occurring for times within one hour of the end of day.
